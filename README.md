# JavaScript Foundations

Study notes and revision guides for a Fundamental JavaScript course.

## Study Guides

- [JavaScript Types](types/javascript-types-study-guide.md): compact exam-focused guide covering primitive and non-primitive types, `typeof`, `undefined`, undeclared variables, TDZ, `NaN`, negative zero, and fundamental objects.
- [JavaScript Coercion](coercion/javascript-coercion-study-guide.md): study guide for abstract operations, primitive conversion, `ToString`, `ToNumber`, `ToBoolean`, and tricky coercion outputs.
- [JavaScript Equality](equality/javascript-equality-types-study-guide.md): study guide for `==`, `===`, `!=`, `!==`, object identity, truthiness vs equality, and common equality corner cases.
